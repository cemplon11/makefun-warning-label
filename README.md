A program that writes the funniest single-line safety warning label that should come printed on every human being, 160 characters or fewer, for make.fun's "Warning Label for Humans: One Line, Big Laugh" bounty.

The label:

> WARNING: This human will nod along to instructions it never heard, then improvise with total confidence. No refunds. No returns.

## Run it

```sh
python3 main.py
```

It writes the label to `/output/entry.txt`.
